# v2
smaller than the initial design, 490 items cheaper, faster load time (yes, even if we're comparing the paper-friendly ver) with the same accuracy, if not even better..

### Building
no hopper timer items needed here, just make sure you aligned the cannon properly to the intersection of 4 chunks based on that stained glass at the top of the cannon in that schematic.

also, make sure to check the sign coords is divisible by 16 (that one sign on top of the stained glass platform)

### Calculator
just use the one in the github pages, how to use it? basically the same. 
Origin of the cannon is the coordinate of a powdered snow block near the nether portal

### Note
you can use the paper-friendly version in a paper server if the server allows tnt duping BUT max-tnt-per-tick is still set to the default (100).
if it allows tnt duping and max-tnt-per-tick is changed to 200 or more, you can just use the original version.
